# ⚾ 야구 포토카드 스튜디오

직접 찍은 야구장 사진과 응원 문구로 나만의 야구 포토카드를 만들어 이미지 파일로 내려받는 웹 편집기입니다.
로그인이나 설치 없이 브라우저에서 바로 쓸 수 있습니다.

## 🔗 웹사이트 주소 : https://github.com/Lee-Minsoo6944/photocard-studio

## 사용법

### 1. 사진 고르기
- 왼쪽 **① 이미지 편집**에서 **이미지 불러오기 (PNG·JPEG)**를 누르거나, 미리보기 위로 사진을 끌어다 놓습니다.
- 사진이 없다면 **직접 만든 샘플 이미지** 버튼(야구장 · 야간 조명 · 야구공 · 공·배트)을 눌러 보세요.
- PNG·JPEG만 쓸 수 있습니다(최대 20MB, 한 변 8000px). 다른 파일을 넣으면 이유가 표시되고, 하던 작업은 그대로 남습니다.

### 2. 화면비와 자르기
- **화면비**를 고릅니다.

  | 화면비 | 크기 | 어울리는 곳 |
  |---|---|---|
  | 1:1 | 1080×1080 | 피드 게시물, 프로필 |
  | 4:5 | 1080×1350 | 인스타그램 피드 |
  | 9:16 | 1080×1920 | 스토리, 휴대폰 배경 |

- 사진은 카드를 빈틈없이 채웁니다. **확대 %**와 **가로·세로 위치 %**로 보일 부분을 조정합니다.

### 3. 카드 꾸미기
- **팀 컬러 프리셋**에서 색 조합을 고르면 테두리·이름 띠·등번호 색이 한 번에 바뀝니다.
- **카드 테두리**를 켜고 끌 수 있고, **테두리 색**과 **포인트 색**을 직접 고를 수도 있습니다.

### 4. 카드 정보와 응원 문구
- 오른쪽 **② 카드 정보 · 문구**에서 입력합니다.
  - **선수 이름**(20자), **한 줄 정보**(40자): 카드 아래 이름 띠에 들어갑니다.
  - **등번호**(4자): 카드 왼쪽 위에 크게 들어갑니다.
  - 비워 두면 해당 부분이 표시되지 않습니다.
- **응원 문구**는 Enter로 줄을 바꿀 수 있고, 이모지(⚾🔥)도 쓸 수 있습니다.
- 위치·크기·글자색·테두리색·굵기·정렬·영역 폭을 바꾸면 미리보기에 바로 반영됩니다.
- 미리보기에서 **문구를 마우스로 끌어** 옮길 수도 있습니다.
- 글이 길어 넘치면 글자 크기가 자동으로 줄어듭니다(**넘치면 글자 크기 자동 축소** 옵션).

### 5. 내려받기
- **③ 내려받기**에서 PNG 또는 JPEG을 고르고 **이미지 내려받기**를 누릅니다.
- 파일 이름은 `card_4x5_20261028-103300.png`처럼 화면비와 시각이 붙습니다.
- **미리보기 ↔ 파일 대조**를 누르면 내려받을 파일이 미리보기와 같은지 픽셀 단위로 확인합니다.
- 내려받은 파일에는 원본 사진의 위치(GPS)·카메라 정보가 남지 않습니다.

### 6. 템플릿 저장하고 다시 쓰기
- 아래 **④ 내 템플릿**에서 이름을 적고 **현재 편집을 새 템플릿으로 저장**을 누릅니다.
- 처음이라면 **예시 템플릿 3개 추가**(홈런 카드 · 직관 인증 · 응원 문구)로 시작해 보세요.
- 각 템플릿에서 할 수 있는 일:
  - **불러오기**: 저장한 설정을 적용합니다. 잘못 불렀다면 위 알림의 **되돌리기**를 누릅니다.
  - **이름 저장**: 입력 칸의 이름으로 바꿉니다.
  - **현재 편집으로 덮어쓰기**: 지금 편집 상태로 템플릿을 수정합니다.
  - **삭제**: 실수 방지를 위해 두 번 눌러야 지워집니다.
- 템플릿은 이 브라우저에 저장되어 새로고침해도 남습니다. 사진은 템플릿에 저장되지 않습니다.
- **JSON 내보내기 / 가져오기**로 템플릿을 백업하거나 다른 브라우저로 옮길 수 있습니다. 형식이 잘못된 파일은 저장 전에 거부되고 기존 템플릿은 그대로 남습니다.

## 이용 시 주의
- 이 도구는 개인이 만든 **팬 제작 도구**이며, KBO 및 각 구단과 관련이 없습니다.
- 구단 로고·엠블럼, 선수 사진, 중계 화면처럼 권리가 있는 이미지는 넣지 마세요.
- 직관 사진을 쓸 때는 다른 관중 얼굴, 좌석 번호가 보이는 티켓, 차량 번호가 나오지 않게 해 주세요.
