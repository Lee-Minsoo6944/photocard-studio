# ⚾ 야구 포토카드 스튜디오

직접 찍은 야구장 사진과 응원 문구로 나만의 야구 포토카드를 만들어 1:1 · 4:5 · 9:16 PNG/JPEG로 내려받는 편집기입니다.
`index.html` 한 파일로 동작하며, 서버·로그인·외부 API가 없습니다.

> 개인이 만든 팬 제작 도구이며 KBO 및 각 구단과 관련이 없습니다. 구단 로고·엠블럼·선수 사진·중계 화면은 쓰지 않습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 편집기 전체 (HTML·CSS·JS) |
| `check_meta.py` | 완성 이미지의 EXIF·GPS 등 메타데이터 검사 (`python check_meta.py a.png b.jpg c.png`) |
| `README.md` | 이 문서 |

## 기능
- **이미지**: PNG·JPEG 불러오기(끌어다 놓기 가능), 확대·위치 자르기, 배경색 지정. 이 페이지가 직접 그린 합성 샘플 4종(야구장, 야간 조명, 야구공, 공·배트 투명 PNG)도 있습니다.
- **카드 꾸미기**: 카드 테두리, 팀 컬러 프리셋 8종(특정 구단 이름이 아닌 일반 색 조합), 왼쪽 위 등번호, 아래쪽 이름 띠(선수 이름 + 한 줄 정보).
- **응원 문구**: 위치·크기·색·테두리·굵기·정렬·영역 폭을 바꾸면 미리보기에 바로 반영됩니다. 미리보기에서 문구를 끌어 옮길 수도 있습니다.
- **템플릿**: 생성·불러오기·이름 변경·덮어쓰기·삭제, 새로고침 뒤 유지, 예시 템플릿 3개(홈런 카드, 직관 인증, 응원 문구), JSON 내보내기·가져오기.
- **검사**: 「미리보기 ↔ 파일 대조」 버튼, 「극단 입력 12건 자동 검사」.

## 공개 배포 (GitHub Pages, 무료·무로그인 열람)
1. GitHub에서 **Public** 저장소를 만들고 `index.html`, `check_meta.py`, `README.md`를 올립니다. (`.claude` 폴더는 올리지 않아도 됩니다.)
2. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**를 누릅니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`가 결과물 주소, `https://github.com/<아이디>/<저장소>`가 소스 주소가 됩니다.
4. 두 주소를 **새 시크릿 창**에서 열어 로그인 없이 보이는지 확인합니다 (T03-C01).

## 설계 요점 (채점 기준과 연결)
- **미리보기 = 파일 (C11~C13)**
  - 미리보기 캔버스 자체가 1080×1080 / 1080×1350 / 1080×1920이고, 화면에서는 CSS로 줄여서만 보여 줍니다.
  - 내려받을 때도 같은 `render()` 함수로 같은 크기 캔버스에 그립니다.
  - 그리기 전에 `document.fonts.load()`로 문구·이름·등번호에 필요한 글꼴 조각을 먼저 받습니다.
  - 그릴 때마다 캔버스 설정을 초기화합니다(아래 결함 2 참고).
- **잘못된 파일 (C09~C10)**
  - 확장자가 아니라 파일 앞부분 바이트로 형식을 판별합니다.
  - 디코딩과 크기 제한(20MB, 한 변 8000px)까지 모두 통과해야 기존 이미지를 교체합니다.
  - 실패하면 이유를 보여 주고 기존 편집은 건드리지 않습니다.
- **템플릿 (C17~C21)**
  - 각 템플릿에 무작위 고유 ID를 붙이고, 수정·삭제는 화면 순서가 아니라 ID로 찾습니다.
  - 목록은 매번 localStorage에서 다시 읽어 그립니다.
  - 삭제는 두 번 눌러야 실행되고, 불러오기는 「되돌리기」를 제공합니다.
- **JSON (C22~C24)**
  - 문법, 구조, 모든 템플릿의 필수 항목·형식·범위를 **전부 검증한 뒤에만** 한 번에 저장하고, 하나라도 틀리면 아무것도 저장하지 않습니다.
  - 필수 항목은 `id, name, ratio, text, x, y, size, color`입니다.
  - 메시지에 가져오기 전후 개수를 보여 줍니다.
- **메타데이터 (C28)**: 내려받는 파일은 캔버스에서 새로 인코딩하므로 원본 사진의 EXIF·GPS가 복사되지 않습니다.
- **안전**
  - 사용자 문구와 템플릿 이름은 `textContent`로만 화면에 넣습니다.
  - 가져온 JSON에서는 알려진 항목만 골라 씁니다.
  - 비밀값·분석 도구·쿠키가 없고, 외부 요청은 Google Fonts(글꼴) 하나뿐입니다.

## 극단 입력 12건 — 실행 기록 (2026-10-28, Chromium, 로컬)
페이지의 「⑤ 극단 입력 12건 자동 검사」로 생성한 결과입니다. **제출 전에 배포된 주소에서 다시 실행하고, 그 결과로 바꿔 넣으세요.**
기본 카드(테두리·등번호·이름 띠)가 켜진 상태에서 검사합니다. 「수정 전 구현」 체크박스를 켜면 같은 입력을 수정 전 방식(글자 코드 단위 줄바꿈, 자동 축소·범위 고정 없음)으로 다시 돌립니다.

|---|---|---|---|---|---|
| 1 | 긴 한글 500자 | "오늘도 끝까지 응원합니다 우리 팀 " 반복 500자, 72px, 1:1 | 모든 줄이 캔버스 안·이름 띠 위, 손실 0 | **FAIL**: 문구 높이 2790px > 1080px, 이름 띠를 덮음 | **PASS**: 16줄, 34px로 자동 축소 |

### 대표 결함 전후 (C15)
1. **이모지 분리 (4번)**
   - 원인: 문자열을 UTF-16 코드 단위로 잘라서 이모지(서로게이트 쌍, ZWJ 결합)가 줄 끝에서 갈라졌습니다.
   - 수정: `Intl.Segmenter`로 보이는 글자(그래핌) 단위로 줄을 바꿉니다.
2. **테두리 모서리 불일치 (미리보기 ↔ 파일 대조에서 발견)**
   - 수정 전: 「홈런 카드」 템플릿에서 대조 결과 "불일치 ✘ 다른 픽셀 280개"가 나왔습니다.
   - 원인: 미리보기 캔버스는 재사용되는데, 앞서 그릴 때 정한 `lineJoin = 'round'`가 남아 카드 테두리 모서리가 둥글게 그려졌습니다. 파일은 새 캔버스라 모서리가 각졌습니다.
   - 수정: `render()` 시작에서 캔버스 설정을 초기화했습니다. 수정 후에는 세 비율 모두 다른 픽셀 0개입니다. 자동 검사도 같은 캔버스에 두 번 그리도록 바꿔, 이 결함이 다시 생기면 잡히게 했습니다.

### 그 밖에 직접 확인한 것 (같은 날 로컬)
- 세 비율 × PNG: 미리보기와 파일의 다른 픽셀 0개. JPEG은 크기가 같고 평균 오차 1.0~1.3(압축 오차)이었습니다.
- 템플릿 3개 생성, 덮어쓰기, 이름 변경, 삭제 후 새로고침: 수정 결과가 그대로 유지됐습니다.
- 정상 JSON 2개 가져오기: 2개 → 4개. 손상 JSON: 거부되고 4개 그대로였습니다.
- `note.txt` 업로드: 거부 이유가 표시되고 기존 이미지가 유지됐습니다.
